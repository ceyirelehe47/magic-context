# Round 33 B · P1-A — R14 judged on structural fold evidence

**Status:** 已复现并修复 (checker false negative; no product change).

## Problem (round 32 C)

`ci-check.py check_r23_history` (R14) decided "this lock-c item was folded by
the second native compaction" by *substring absence* from the model-visible
surface. In run 42034146821 the model stored the five checksums with
`ctx_memory`, the historian quoted them, and the lock-d checkpoint (seq 224)
restates them. The probe found them in the checkpoint text → `shadowed=[]` →
the non-vacuity guard failed although the fold happened, nothing was lost and
the summary reached compartment 32-43.

## Change

`scripts/e2e/ci-history.ts` (data only; same CLI, same output file) adds per
item (prompt + every checksum read):

| field | meaning |
|---|---|
| `originSeqs` | the raw event(s): the read's `tool/result`; for the prompt every un-derived `user/message` holding the needle |
| `shadowedBy` | every `compaction/summary` whose `shadowedSeqs` holds an origin seq **or a node derived from it through `sourceEventSeqs`** (Magic's surface-replace copy of the read — e.g. 163 → 165 — and anything derived from that) |
| `onRawSurface` | the text is on the surface **outside** every summary node's own text. Summary node = a `user/message` whose `sourceEventSeqs` name a `compaction/summary`, or a copy whose sources are all summary nodes (Magic's tagged copy of a checkpoint). Their texts (minus a leading `§N§ `) are cut out of each surface message before probing, so a raw message — or a Magic injection, or anything merged into the checkpoint's message — that still carries the text counts |
| `inSummaryText` | diagnostic: the text is in a summary node's own text |

`ci-check.py` R14 now reads them.

## Old vs new semantics

| conjunct | old (≤ round 32) | new (round 33) | relation |
|---|---|---|---|
| lock-d rc=0, `/compact` done `kind=success`, ≥ 2 compactions, prompt found, files found | same | same | unchanged |
| "folded" (non-vacuity guard: ≥ 1) | text absent from the whole surface | `shadowedBy` non-empty **and** `onRawSurface` false | text only in a summary no longer counts as unfolded (the intended change); text gone with no compaction fold (e.g. a Magic drop) no longer counts as folded (stricter); text on a raw message is unfolded in both |
| `lost` | not on the surface (summary text included) and no compartment | not on the **raw** surface and no compartment | stricter: a summary quoting the text no longer rescues an item |
| summary reaches | max ordinal of "not on surface" ≤ last `summaryMaxEnd` | max ordinal of everything not on the raw surface (folded or otherwise gone) ≤ last `summaryMaxEnd` | stricter (superset of items) |
| item gone from raw surface without a history ordinal | not checked | FAIL (`unplaced`) | stricter |
| history-lock.json without the structural fields | n/a | FAIL (`basis: MISSING …`), never a silent fallback to the old basis | stricter |

"recoverable from a compartment" is still the range test (`coveredBy`) =
what `ctx_expand(start, end)` of that compartment returns — unchanged.

## Limits

  with `python3 packages/dsh-plugin/scripts/e2e/test_ci_check_r14.py`.

  carries a checksum on the final surface the item counts as unfolded (can
  only cause a FAIL, never a false PASS).
